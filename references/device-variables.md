# 触摸屏设备变量与绑定

本文仅说明触摸屏工程内设备通道、数据对象和控件绑定的离线处理，不涉及外部控制器程序、握手状态机或控制器编程工具。

## 先读原配置

记录软件完整版本、目标屏及设备驱动版本，从当前工程读取通道名、对象 ID、对象类型、地址和驱动配置。未知字段保留原字节，不能根据界面显示名推测真实绑定。

设备地址和驱动参数属于用户工程。修改页面或字体时应保持它们不变；需要修改设备通道时，先确认该版本的记录结构和实际需求，单独列出允许变化的字段。现有通用写入器不因此获得任意设备表写入权限。

## 绑定一致性

- 控件显示名称、表达式中的变量名、缓存中的对象 ID 和原生类型应对应同一个真实数据对象。
- 新建本地对象应使用同类原生模板，确认名称和 ID 唯一，保留原对象 ID 及未修改的指针关系。
- 不能把本地变量当成已经导入的设备通道，也不能用同名文字代替真实对象或配方注册。
- 连续对象的 ID、成员顺序和类型需要逐项核对；名称相邻不代表原生记录连续。
- 设备命令中的类型码依赖具体驱动及版本。保留已验证配置；缺少同版本依据时标为待验证，不根据另一驱动的数字照搬。

## 验证层次

离线检查可证明名称、ID、类型、记录结构和修改边界一致。设备命令返回成功、离线预览中的数值变化不能证明外部设备已经接收或执行。

提交设备绑定方面的改动，应提供脱敏后的最小触摸屏样例、驱动及软件版本、修改前后字段差异，以及原厂组态检查结果。需要实际通信才能确认的部分单独标注，不作为纯离线自动检查已经通过的内容。
