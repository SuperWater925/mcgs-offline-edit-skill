# 接收电脑上的原厂验证

本包的文件编写链路不启动编辑器。文件侧回读通过后，接收方Codex再使用本机获准的应用操作工具，完成以下原厂验证。没有相应工具或权限时报告阻塞，不声称已完成。

1. 核原厂程序版本为McgsPro 3.5.1.6963。关闭本任务已有验证实例，只操作本任务自起实例，不干预用户编辑中的工程。确认工程副本、目标机型和现场连接断开。
2. 打开生成的MCP，核页面、控件与变量清单。遇到损坏、缺驱动、缺字体或版本转换提示停止并记录实际内容，不能自动忽略。
3. 执行全部窗口检查，记录真实错误和警告。零错误才继续；原有警告和新警告分别解释。
4. 原厂保存、正常关闭、重新打开，再检查。回读页面/变量/绑定，确认内容保留；保存产生的缓存变化单列，不把文件SHA必然不变当验收条件。
5. 选择本机模拟、联机关闭后编译。按实际软件控件确认状态再执行，禁止现场下载或运行环境升级。零编译错误并有新编译产物才通过。
6. 对受影响内容做短时本机模拟：标签及布局、数值输入上下限、绑定值变化和初值。仅操作已确认不连现场的实例，测试值结束后复原。正常退出模拟器和编辑器。

已知版本的F4用于检查、F7打开运行配置；快捷键本身不能证明安全模式或完成。必须读取原厂检查结果、模拟/联机选项和编译结果。自动化工具按原生控件/API/受支持消息使用，不凭截图坐标猜测输入。

记录文件回读与原厂验证两个独立状态：文件回读状态、实际程序版本、打开/检查/保存重开/编译结果、警告、模拟覆盖与未完成项。写入回执`host_validation=pending`需在这些步骤实际完成后才能更新交付说明。未连接真实设备时仍为`physically_tested=false`。

制作电脑目录运行包仅在用户要求时通过原厂功能验证，使用全新目录，关闭环境升级及删除其他工程选项，核成功提示和完整输出。本地包制作不包含安装到现场设备的授权。
