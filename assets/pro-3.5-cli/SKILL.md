# 昆仑通态离线工程文件编写

目标版本固定为McgsPro 3.5.1.6963。使用随包脚本直接创建和修改`.mcp`，不通过编辑器代替文件生成。脚本、通用空白数据和控件模板全部随包提供，不依赖作者项目目录或MCP服务。

首次使用读[安装与命令](references/runtime.md)，运行`run.cmd doctor`。再读[工程规格与修改](references/editing.md)，由用户需求生成JSON规格并实际运行create/edit。不要只交一份设计文字或把JSON改扩展名冒充工程。

## 实施流程

1. 区分新建或已有原生工程修改。新建按随包800×480目标模板；修改先inspect，核版本、SHA和对象。缺少地址/协议等设计依据时不编造现场配置。
2. 将需求转换为JSON，调用`run.cmd create`或`run.cmd edit`生成新路径。支持范围见editing.md；未知字段和不支持的控件应明确报告，不能丢弃后称为完成。
3. 检查成功回执、12张表全量回读、输出SHA和inspect结果。修改需原文件SHA及受影响控件原始SHA；原件不覆盖，未涉及的表和记录保留。
4. 文件编写完成后，在接收方电脑按[原厂验证](references/acceptance.md)自动执行打开、检查、保存重开、编译及相关本机模拟。此时才使用原厂软件；遇到权限、缺失工具或未知弹窗说明具体阻塞，不伪报通过。
5. 交付实际MCP路径、修改摘要、文件回读与原厂验证各自结果。文件写入成功回执中的`host_validation=pending`不是编译通过。

## 当前可执行范围

- 新建一页或多页工程，第一页作为启动页；基础目标模板为800×480。
- 新增布尔、数值、字符串变量，设置初值、注释和单位。
- 新增标签、线、矩形、数值输入；设置名称、矩形位置，标签文字，数值输入绑定及上下限。
- 修改已有工程中相应控件的受支持属性，新增这些控件，修改变量初值/注释/单位以及新增变量。
- 不支持的其他组件、设备协议配置、复杂脚本和策略需要另行实现；不得宣称任意功能都能生成。不通过删掉原工程里的未知组件来适配工具。

## 操作边界

写入仅在本机新文件中进行，不连接设备。现场设备仅允许已确认不影响运行的只读查看；禁止下载、写数据或改运行参数。保留原权限、账号、密码和其他未指定内容；不输出凭据。未知版本、源SHA或控件SHA不匹配即停止，不跳过校验。

原厂软件仅用于验证。未连接设备时记录`physically_tested=false`；本机模拟的值变化不等于PLC或真实设备动作成功。
